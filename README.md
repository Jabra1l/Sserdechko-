# Heart Site — GitHub Pages

Статическая версия сайта без Flask и Python. Она работает прямо через GitHub Pages.

## Публикация

1. Замените содержимое репозитория `heart-site` файлами из этой папки.
2. Отправьте изменения в ветку `main`.
3. На GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Нажмите **Save**.

Сайт будет доступен по адресу:

`https://jesterisme.github.io/heart-site/`

## Локальная проверка

Можно просто открыть `index.html` в браузере.
